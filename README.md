# 연금저축·IRP 세액공제 계산기 · 똑재TV

올해 연금저축·IRP에 넣은 돈으로 연말정산 때 돌려받는 세금(연금계좌 세액공제)과, 12월 31일까지 한도를 채우면 더 돌려받는 금액을 계산하는 계산기.

- 사이트: https://ttokjaetv.github.io/pension-credit/
- 근거: 소득세법 제59조의3(2026-01-01 시행본), 시행령 제40조의2(연 1,800만원 납입한도)·제118조의3(공제 못 받은 납입액 전환 신청). 2026-10-24 국가법령정보센터 원문 확인.
- 계산
  - 공제 받는 납입액 = min(연금저축(600만원 한도) + IRP 의 900만원 한도 + ISA 만기 전환금액의 10%(최대 300만원, 두 해에 걸치면 합쳐서), 전체 납입액)
  - ISA 전환금액도 일반 납입처럼 600·900만원 한도에 들어간다(제59조의3③). 퇴직금 IRP 입금·계좌 이전은 제외(①1·2호).
  - 돌려받는 세금 = 공제 받는 납입액 × 소득세 15%(총급여 5,500만원·종합소득금액 4,500만원 초과면 12%) + 지방소득세 10%, 원 미만 버림
  - 결정세액(연금계좌 세액공제 전, 소득세)을 넣으면 소득세 공제를 그 금액까지만 센다
- 제도 숫자는 모두 허브 `rules/v2026.2/rules.js`(`PENSION_SAVINGS`, `INCOME_TAX.local`, `PENSION`)에서 읽는다. 정적 문구 숫자는 `fill-v1.js`(`data-rule`).

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html` 생성. 엔진 시험은 `node src/test.js` (기대값은 법령 손계산). 자동 검사(rules-guard)가 빌드 결과·시험·하드코딩을 확인한다.
